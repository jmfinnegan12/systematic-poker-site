# About - Systematic Poker
## Mission
We help small stakes online poker players with simple study tools and an actionable, systematic approach to their play — so they can become profitable and move up in stakes.

## About
I suck at poker. And I want to get better. Poker players looking to improve their game are already overwhelmed by all the products vying for their attention. These tools cover the full spectrum: from extremely helpful for disciplined users all the way to outright scam. They are available at a wide range of prices (some free) for anyone at just about any skill level. Instead of just using one of the existing tools, I decided to join the race to the bottom and build my own!  

Why? It will be much more fun that way.  

My goal is simple: I want to analyze my performance and my opponents' tendencies to learn how I can improve. 

My current poker bankroll does not have the ...spare capacity... for a human coach or a sophisticated software package that is sufficiently customizable (if one exists) to meet my goal, so I am vibe coding my own. 

I don't want to become a professional poker player, but I enjoy playing the game and want to learn how I can improve. This is my project to do so. 

The project is an iterative process:
1. play poker
2. improve the tool to better analyze my performance
3. study the output of the tool
4. document and publish my findings
5. repeat

My primary goal for this project is to become a better poker player. I want to use the tool to move from micro to small or mid stakes online. If I manage to do that, I expect that I will have built a useful tool, and I will want to keep enhancing the tool and my game from there. I am documenting the process for myself and those interested.
